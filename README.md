# Yoga Studio — Operations Dashboard

Prototipo web para gestionar la operación de un estudio de yoga, con reservas, créditos, control de capacidad y un dashboard de indicadores operativos.

**[Demo](https://yoga-studio-prototype.netlify.app)**

## Funcionalidades

- Gestión de clases y reservas.
- Control de créditos, cancelaciones y asistencia.
- Listas de espera con promoción automática.
- Dashboard con ocupación, disponibilidad y actividad reciente.
- Filtros por período y estado de las clases.

## Tecnologías

HTML · CSS · JavaScript · localStorage

## Estado

Prototipo funcional con datos ficticios. No tiene backend, base de datos remota, autenticación real ni sincronización entre dispositivos. El dashboard es de consulta y no modifica las operaciones.

## Contexto

Proyecto desarrollado para **Fundamentos de Product Engineering con IA**, de Código Facilito.
